# Scoreboard live excel export

It is possible to export data to an Excel sheet from both the main scoreboard [https://help.hhtiming.com/displays/scoreboards/main-scoreboard] and the driver scoreboard [https://help.hhtiming.com/displays/scoreboards/driver-scoreboard]. This is a separate function from that of the live Excel export [https://help.hhtiming.com/excel-exports/live-excel-export] function which is more generalised. The scoreboard Excel exports simply sends a copy the scoreboard to the specified Excel sheet every 10 seconds.

In the case of the main scoreboard [https://help.hhtiming.com/displays/scoreboards/main-scoreboard], using the Column Config to customise what is shown, a huge range of data is able to be passed to an external Excel sheet. The driver scoreboard [https://help.hhtiming.com/displays/scoreboards/driver-scoreboard] Excel export would typically be used to perform driving time calculations for the entire field to automatically identify driving time infringements for the whole field.

The export can be configured in the ribbon bar control for the relevant scoreboard as highlighted below:

![](https://help.hhtiming.com/assets/images/scoreboard_live_excel_1-66a57892e2280cecb18cc0d1ed879f0d.png)

Clicking on the Configuration button opens the following display where the Excel workbook path, worksheet name and row/column positions are input.

![](https://help.hhtiming.com/assets/images/scoreboard_live_excel_2-6690b50475e166602bd613ae4b3ff73a.png)

Clicking Start Export then starts the export.

tip
Note that multiple Excel exports can be run simultaneously if required.

tip
To export the Main Scoreboard in its default configuration:

![](https://help.hhtiming.com/assets/images/scoreboard_live_excel_3-da7b321845bc69354f8f5ee0a16e34b5.png)

Once exported to the Excel sheet of choice with the default row/column settings will look as below:

![](https://help.hhtiming.com/assets/images/scoreboard_live_excel_4-9ec30622e9931faf9beb0fe0815d1a5f.png)
