# Reporting

HH Timing has extensive reporting tools available. The purpose of the reporting functions is to quickly generate timing reports and save them in a format that does not require HH Timing to view them. Timing reports are able to be saved in both PDF and HTML format, this allows reports to be shared with drivers and team members without needing HH Timing to view and interact with them. Detailed information for the Reports section is separated into sub-areas.

## HTML Format​

HTML reports are opened in an internet browser. Making reports in HTML format has the advantage that some interactivity is possible [https://help.hhtiming.com/reporting/viewing-reports]. This makes the report more flexible and useful, particularly when a lot of cars are part of an event.

## PDF Format​

PDF reports are opened in any PDF viewing program. Unlike the HTML format they are static and can not be manipulated in any way.
