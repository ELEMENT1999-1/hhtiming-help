# Session data recovery

If your computer crashes during a session, it is possible to recover the software the its previous state before the crash. This allows you to recover from a crash with minimal interruptions.

To recover a session after having problems:

- Click the Recover button in the Data tab
- Select the session to recover (generally the session you were just connected to)
- Reconnect to the live session
- Click "No" when asked if you want to clear the scoreboard

![](https://help.hhtiming.com/assets/images/recovery_1-7d45812f0b2371d8c4cbb5c5b19e63a7.png)

After these steps are followed, the live timing data will be appended to the data that was recovered. This means all data from that session will remain part of single data collection.
