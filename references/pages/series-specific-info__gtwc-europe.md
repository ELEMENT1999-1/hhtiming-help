# GTWC Europe

## Live Data Connection​

You can find more information about how to connect to Swiss Timing FTP Protocol here [https://help.hhtiming.com/timekeeper-specific-info/swiss-timing].

### Championship Configuration in HH Timing​

Once located, this information needs to be entered in the appropriate championship configuration.
By default, a championship called “GTWC Europe” is created in all new projects.
Double click on this item to open it in your workbook.  Enter the path in the “Additional Connection Information” field as shown in the following screenshot.

A Kafka feed is also available, either locally on the timing network or remotely via the cloud host. See the Swiss Timing Kafka [https://help.hhtiming.com/timekeeper-specific-info/swiss-timing/#kafka-connection] section for general setup. The connection details for GTWC Europe are:

Local (timing network at the circuit):

 |  |
| Protocol | Swiss Timing Kafka
| Host | 10.2.40.3
| Port | 9093
Cloud:

 |  |
| Protocol | Swiss Timing Kafka
| Host | evhns-prod-realtime-msp-westeurope.servicebus.windows.net
| Port | 9093
By default, a championship called "Swiss Timing Kafka" is created in all new projects. Double click on it to open it in your workbook and verify the settings above.

## Plugin​

Don't forget to download the Drive Time Plugin. You can find it on hh-dev.com (you will need to be connected) or directly here.

## Track Limits Warning​

Track Limits Warning are sent in the feed in GT World Challenge Europe. It will be displayed in the main scoreboard, the car scoreboard, the driver scoreboard and the Track Limit Warning display. You can find specific help file here [https://help.hhtiming.com/displays/track-limits-warning].

## Multi Session Scoreboard​

In qualifying you can use the Multi Session Scoreboard. You can find more informations about it here [https://help.hhtiming.com/displays/scoreboards/multi-session-scoreboard].
