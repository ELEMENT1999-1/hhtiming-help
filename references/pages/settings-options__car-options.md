# Car options

Car project items can be edited by clicking the “Car Options” button on the Components tab of the ribbon bar. This will open a new window that will allow you to edit parameters for each car.

![](https://help.hhtiming.com/assets/images/car_options_1-bc9552a6b963b7e243807c02a0c01924.png)

The following parameters can be adjusted for each car:

- Report name
- Category
- Colour
- Team name
- Car manufacturer
- Tyre manufacturer
- Line style (for graphing only)
- Line colour (linked to the car colour)
- Line width (for graphing only)
- Marker style (for graphing only)
- Marker colour (for graphing only)
- Marker size (for graphing only)
The following parameters can be adjusted for each driver using the bottom right quarter of the window:

- Report name
- Driver Categorisation (e.g. Platinum, Gold, Silver, Bronze)
- Colour
- Line style (for graphing only)
- Line colour (linked to the driver colour)
- Line width (for graphing only)
- Marker style (for graphing only)
- Marker colour (for graphing only)
- Maximum Driving Time (Minutes)
- Minimum Driving Time (Minutes)
A button is available in the grid to apply the `Max Dr [min]` and `Min Dr [min]` values from one driver to all other drivers that share the same `Driver Categorisation`.

- If a driver has a categorisation (e.g., "Gold"), clicking the button will apply their driving times to all other "Gold" drivers.
- If a driver has no categorisation, clicking the button will apply their times to all other drivers that also do not have a categorisation.

![](https://help.hhtiming.com/assets/images/car_options_2-00c8749f06a548aa85bcd2f5bd8057ac.png)
