# Sanitized average lap time

The sanitized average lap time for each car is calculated as follows:

- Start with all laps for a stint
- Remove all safety car/ full course yellow/code 60 laps
- Remove all in and out laps
- Calculate the average of the remaining laps
- Remove all laps 20% above the average (this value is currently a fix value in HH Timing)
- Recalculate the sanitized average using the remaining laps
