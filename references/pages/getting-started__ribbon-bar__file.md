## Service​

### Submit statistics data to HH Timing​

Manual submission of statistics and updating of some software elements. As long as the computer has an internet connection these generally happen automatically each time the software is started.

note
For statistics to be sent and updates applied automatically these must be set as True in the Options

### Update all track maps and report definitions​

Perform a server check to ensure all track maps and report definitions are up to date. This is mainly used when a new track map is released during an event, allowing track map updates without a software restart.

note
This function perform a check on our cloud server so a connection to internet is required
