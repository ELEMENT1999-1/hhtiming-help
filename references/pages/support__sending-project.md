# Sending an HH Timing project

In some cases we will ask the project to be sent to use to properly understand an issue a user has. The entire project folder needs to be sent (not just the project file), the default location all project folders are stored is:

```
C:\Users\YOUR_USER_NAME\Documents\HH Timing\Projects
```

The project path can also be found in the software backstage under Project Management:

![](https://help.hhtiming.com/assets/images/sending_project_1-1c3029337fbc2f6e3ef45918606b32e9.png)

caution
The contents of the project folder will look like this as follows, with the project file itself in the red box:

![](https://help.hhtiming.com/assets/images/sending_project_2-b50334d04b8da3ad522b896572a43582.png)

Zip the entire folder that contains the above components and send this to us with your choice of file sharing tool such as Dropbox, WeTransfer etc.
