# Multi-session scoreboard

The multi session scoreboard allows multiple sessions to be combined to find the final ranking. It is intended to be used when multiple sessions determine the qualifying ranking.

![](https://help.hhtiming.com/assets/images/multi_1-6808033a05b36ec6af257fcdcedd3820.png)

To choose the sessions to be included, use the Select Sessions button in the ribbon bar control. There is an option to use the average of the best of each session to calculate the ranking. If this is not selected then the best of any of the sessions for each car determines the ranking.
