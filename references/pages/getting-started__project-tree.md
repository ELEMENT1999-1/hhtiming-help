# Project Tree

The project tree is found on the left side of the software. It contains some of the project configuration information and session data and is broken into 3 main sections:

- Displays
- Components
- Data
The tree as it appears in a new project is shown below:

![](https://help.hhtiming.com/assets/images/general_1-a759e592bb00aee95e7d2b00f944d72c.png)

tip
You can collapse the tree by hovering over the vertical bar that separates the tree from the rest of the project and left clicking. Click on this bar again to show the tree view again.
