# Championship point scoreboard

The Championship scoreboard allows live tracking of the championship situation during an event.

![](https://help.hhtiming.com/assets/images/championship_1-56ce1e1a4e4993ca9ab2c92cdc0218fe.png)

The starting points can be input in the Championship points ribbon bar using he Starting Points button. They can be entered manually or imported/Exported between projects if required.

![](https://help.hhtiming.com/assets/images/championship_2-24ba69864bd88ed27d1597a846ca9284.png)

The points structure is defined in the Championship configuration [https://help.hhtiming.com/settings-options/championship-configuration].

![](https://help.hhtiming.com/assets/images/championship_3-7dc03d5d1f4cd742f69e95f43f89c301.png)

## Manufacturers points modes​

In these modes, the scoreboard calculates the total points of each manufacturer according to the organization rules.

![](https://help.hhtiming.com/assets/images/championship_manufacturer-2e75d804f97117906951560ec95728eb.png)

To filter the displayed manufacturers use the "Allowed Class" filter in the ribbon bar. With this filter, the view will show only manufacturers racing in the desired class.

[内嵌示意图]

There are two modes of manufacturer points:

### IMSA​

In this mode, the manufacturers are ordered by the position of its best car on track. Points are calculated using the manufacturer position in the ordered list.

![](https://help.hhtiming.com/assets/images/championship_manufacturer_points_IMSA-d97215077b3cc53f0292e073f73c98b3.png)

### WEC​

In this mode, the points are calculated using the class position of the best car of each manufacturer.

![](https://help.hhtiming.com/assets/images/championship_manufacturer_points_WEC-6c184b3a457821cb4490895dd7f6650a.png)
