# FormulaE

In Formula E, Alkamel [https://help.hhtiming.com/timekeeper-specific-info/alkamel-v2] is the timing provider.

## Alkamel V2 Protocol​

Prior to get access to the timing data, make sure that you have contacted Alkamel:

- There is a fee that is usually a per championship fee.
- You would need to get Alkamel to enabled V2 protocol for your team.
- They should provide you with credentials.
- They should provide you a router and a WIFI antenna.
- They should also provide you with a Network configuration.
You can find specific help file for V2 protocol here.

## Championship Configuration​

You will need to create your own. Our help file will help you to set up a new championship configuration.

## Backstage Options​

There is many options in the backstage dedicated to Formula E.

[内嵌示意图]

You can set up the Attack mode length, the Extra Time Session Elapsed Time Limit, the Maximum Extra Time and the number of activations. The Session Extra Time will be automatically update during the race. If it is different from the value sent by the marshals after 40 minutes, you can update it here.

## Yellow Flag Periods​

You can add a column Extra Time on the Yellow Flag Periods to know the Extra Time associated with each Full Course Yellow or Safety Car period.

## Plugin​

You can download the latest version of our Formula E plugin on our website.

### Formula E Best Sector Scoreboard​

This scoreboard is the same than the Best Sector Scoreboard but you can select the Power Mode to have only 250kW times or only 220kW times.

### Formula E Remaining Time Scoreboard​

This scoreboard displays the Remaining Time for the leader in the race until the end of the 45 minutes + the extra time. After 40 minutes, the extra time cannot be increased so the first two columns (Time Remaining and Time Remaining With Extra Time) will display the same values.

## Troubleshooting​

If you can't connect, it may come from a network problem, from wrong credentials or because you reached the maximum number of connections.

### Wrong credentials (V2 Protocol)​

Please ask Alkamel to confirm that you are using the right credentials to connect to the feed.

### Number of connections​

Alkamel limit the number of connection. You can use the server mode [https://help.hhtiming.com/timing-data-management/hh-timing-server-mode] to avoid any issue with the limited number of connections.
