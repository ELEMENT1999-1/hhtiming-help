# MyLaps HTML Scraping - Speedhive

When the timing is provided on https://speedhive.mylaps.com/ then the MyLaps HTML Scraping protocol can be used.

## Live Data Connection​

The connection to the live timing feed is done via the internet. If a stable wired internet connection isn't available, connecting to a mobile phone hotspot typically works well.

Create a new championship configuration [https://help.hhtiming.com/settings-options/championship-configuration] and select the # MyLaps HTML Scraping Protocol as shown below.

![](https://help.hhtiming.com/assets/images/mylaps-speedhive_1-6d921848db914fbb5ff163a03707924d.png)

The host is the base address of the active live timing so the active session should be in full screen in the live timing.

![](https://help.hhtiming.com/assets/images/mylaps-speedhive_2-a57bbd5e9569c4b43a9b4f2101d0c167.png)

![](https://help.hhtiming.com/assets/images/mylaps-speedhive_3-bdcfd4b99f19373689e1ac5bb7efa0fa.png)

The number of Sectors needs to be defined, and will be the number of active sectors.
If the live timing displays more sectors than active sectors, with 1 unused sector between each sector, a parameter "skip 1 sector out of 2" can be add and set to true.
