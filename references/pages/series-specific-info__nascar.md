# NASCAR

## Championship Configuration​

Nascar protocol is a special version of the multiloop protocol.

[内嵌示意图]

### SF management​

In the NASCAR protocol there are no lap sectors, all the information is lap based and only laptimes are displayed. The software has a list of pre configured SF lines in order to manage the different tracks.
If the SF is not recognized, the list of possible SF lines can be defined as an option in the championship configuration. The parameter to set this list is called "sf lines" and multiple items can be defined by concatenating them with a comma (Item1,Item2....)
