# Circle track map

The circle track map is a linearised representation of the full track map where each sector is shown as equal length. Class leaders are shown with rectangle icons with the rest of the cars shown with small circles. The start/finish line is always shown at the top and the user has control over whether the cars move in a clockwise or anticlockwise direction.

![](https://help.hhtiming.com/assets/images/circle_1-df005afd6f9ce00ca3a80cbc46f28134.png)

## Car Position Methods​

### Default​

Car positions are interpolated from timing line crossings in the same way as the full track map. Each car's position within a sector is estimated based on that car's historical sector times, continuously corrected at each timing line.

### Use Computer Time​

See Use Computer Time To Draw Positions [https://help.hhtiming.com/displays/track-maps/#use-computer-time-to-draw-positions] in the shared track map settings.

## Show Gap Overlay​

The Show Gap Overlay feature is now also available for the Circle Track map.

![](https://help.hhtiming.com/assets/images/circle_2-da2e1655f35e674c007f91549fa7f198.png)

See Show Gap Overlay [https://help.hhtiming.com/displays/track-gap-display/#options] in the track gap display settings for more details.
