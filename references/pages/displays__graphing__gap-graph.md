# Gap Graph

The gap graph is only used to analyse a race and shows the gap between a reference and other cars in the field. On the y-axis the gap to the reference is shown in seconds, and on the x-axis the lap number of the raceor the session elapsed time is shown.

The gap chart is useful for analysing the pace of the reference car over periods of laps (e.g. stints and/or the whole race) relative to the other cars shown on plot. Because a number of laps are studied there is a filtering effect that gives a much clearer picture of the relative pace of the two cars compared with looking at raw lap time data.

## Gap Convention​

As default, positive y-values indicate that a car is behind the reference, and negative y-values indicate that a car is ahead of the reference. This convention can be reverted using the "Reverse Y Axis" option in the ribbon bar

![](https://help.hhtiming.com/assets/images/plotting_11-ef8d2e83912780e66fed69ac3fe63e1c.png)

## Reference Modes​

There are 2 difference modes that can be used to set the reference as shown below.

![](https://help.hhtiming.com/assets/images/plotting_5-63fc1d9f95d2dfb07caedd31a4b39064.png)

### Reference Car​

The gap of every car relative to a chosen reference car at the end of each lap.

![](https://help.hhtiming.com/assets/images/plotting_6-551c46123e862916d2d6a8c10721a0ef.png)

### Reference Time​

The gap of every car relative a lap time. This can be thought of as the gap to a hypothetical car that does the exact same lap time for the entire race.

![](https://help.hhtiming.com/assets/images/plotting_7-2bbb4ca52235043fd249c730a35233d6.png)

To edit the reference time use the button in the ribbon bar:

![](https://help.hhtiming.com/assets/images/plotting_8-821faf9bf0ddf816fba22f79ceb646ce.png)

A pop up window will show up allowing the option to update the graph per lap or per sector.

![](https://help.hhtiming.com/assets/images/plotting_9-10c27d35e78d5524abcbcea5bdb8d087.png)

## Reference Lines​

Horizontal reference lines can be added to the graph from the Edit Reference Lines button.

Each reference line includes a name, a Y-axis value, and a color selection.

[内嵌示意图]

The line appears on the charts, with the name shown on the right to differentiate multiple lines.

![](https://help.hhtiming.com/assets/images/reference_3-d435f891fe8a6fc03c84c0d6d5ef4249.png)

## X Axis Modes​

There are two modes for the horizontal axis.

![](https://help.hhtiming.com/assets/images/plotting_10-2bad49a230f0eadecbf078ecd6e644e8.png)

## Laps down display​

Only available in Reference time mode

The option "Laps down to show" controls the number of lap down that are displayed in the graph. That is the theoretical gap of a car that x laps behind the leader according to the pre defined reference lap time.

![](https://help.hhtiming.com/assets/images/plotting_12-639d8d1b0026ee5993d68b9d135f735e.png)

## Reset under yellow​

Only available in Reference time mode

When this option is enabled, the leader gap is reset to 0 after each yellow lap. The gap of the other cars is corrected using the offset applied to the leader gap

![](https://help.hhtiming.com/assets/images/plotting_13-ce869a68d35eeae965c59718ce1534b8.png)

## Single-class mode​

Only available in Reference time mode

In multi-category races, the laps down display and the reset under yellow feature operate independently for each category leader. When "Single-class mode" is enabled, all cars are treated as racing against the overall leader. The laps down lines are only shown for the overall leader's category, and the reset under yellow offset is based on the overall leader's category rather than each car's own category.

## Track status highlight​

In periods where the track is not green, the background of the graph changes to the color of the track status flag (yellow for SC, purple for FCY)

![](https://help.hhtiming.com/assets/images/plotting_17-e36dc7d9fb0db01f00276fae3fb1c554.png)

This option can be disabled using the "Show Track Status" option in the ribbon bar

![](https://help.hhtiming.com/assets/images/plotting_18-9e2d2a3dbc635c00c7313d601a34ccb2.png)

## Ghosts​

The ghost lines represent the gap at which a given car will land after a pit stop at the end of the current lap. There are two types of ghosts, "Fuel" and "Fuel and Tyres". The car selection is done by manually writing the car number into the ribbon bar controls. Multiple cars can be entered by joining them with a comma (",")

![](https://help.hhtiming.com/assets/images/plotting_14-76676e74718fa7290a53d7edf307924d.png)

![](https://help.hhtiming.com/assets/images/plotting_15-ac002734e38db0ae63c44257388eea37.png)

## Projected laps​

The projected lap option shows a line per car with the evolution of the gaps in future laps based on the car average laptime. The number of laps ahead is controlled by the value in the ribbon bar.

![](https://help.hhtiming.com/assets/images/plotting_16-9f17f094048ea37d104d2942e222ff30.png)
