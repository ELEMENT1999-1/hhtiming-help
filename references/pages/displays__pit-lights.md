# Pit Light Display

Series
This display will only work in WEC and ELMS.

## Mode Selection​

The Pit Light Display can operate in two distinct modes:

- Pit Entry
- Pit Exit
The mode can be selected using a dropdown menu located in the ribbon bar:

[内嵌示意图]

## Status Display​

The current light status is visualized using a vertical traffic-light layout consisting of three circular indicators:

![](https://help.hhtiming.com/assets/images/pit_light_3-41a0ee0496b7c51f6ef774b68c94daf4.png)

Each circle corresponds to a specific color signal:

- Top circle: Red — pit entry/pit exit closed; grey when inactive
- Middle circle: Green — pit entry/pit exit open; grey when inactive
- Bottom circle: Blue — blue flag; grey when inactive`
The labels "PIT ENTRY" (or "PIT EXIT") are shown vertically on either side of the lights, depending on the selected mode.
