# Displays

Custom scoreboards [https://help.hhtiming.com/displays/scoreboards], graphs [https://help.hhtiming.com/displays/graphing/scatter] and screen layouts [https://help.hhtiming.com/workbooks-layouts] within a project are shown in the Displays section of the project tree.

![](https://help.hhtiming.com/assets/images/displays_1-8ca8e2770d8218bfd9305609e27645b8.png)

## Scoreboard Templates​

A scoreboard [https://help.hhtiming.com/displays/scoreboards] that you customize can be saved as a template to be used again as shown in the tree above. To add this scoreboard [https://help.hhtiming.com/displays/scoreboards] to your current layout right click and select open on the tree item.

## Graph Templates​

A graph [https://help.hhtiming.com/displays/graphing/scatter] that you customize can be saved as a template to be used again as shown in the tree above. To add this graph [https://help.hhtiming.com/displays/graphing/scatter] to your current layout right click and select open on the tree item.

## Layouts​

Saved screen layout [https://help.hhtiming.com/workbooks-layouts] are stored in the project tree as shown above. To load a layouts [https://help.hhtiming.com/workbooks-layouts], right click and select load.
