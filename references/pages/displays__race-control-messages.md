# Race Control Messages

When available, the Race Control Messages display shows messages sent by the organizer.
By default, it displays the session time (hh:mm:ss) and the message:

![](https://help.hhtiming.com/assets/images/race_control_messages_4-3cd90d691444a27a4b6e164ad8481619.png)

## Reference Car​

The reference car can be changed in the ribbon bar, highlighting all messages related to this car using the car's color. Here is an example with car 51:

![](https://help.hhtiming.com/assets/images/race_control_messages_5-5f39402fab9723498deffcf012bac253.png)

![](https://help.hhtiming.com/assets/images/race_control_messages_3-b5d5173671725b1d4adcd850a3a3bd02.png)

Multiple reference cars can be used by separating them with commas:

![](https://help.hhtiming.com/assets/images/race_control_messages_6-2559cd1552195715bfa700e825303cfa.png)

![](https://help.hhtiming.com/assets/images/race_control_messages_7-39aaf0bf8ffe655ee0cfa397c028bc36.png)

## Using time of day​

In some protocols, the time of day is sent, allowing it to be displayed instead of the session time. To enable this, the option "Use Time of Day" must be checked:

![](https://help.hhtiming.com/assets/images/race_control_messages_9-a06623f7ee9814a89778553a80a3fb1f.png)

The time of day sent by the feed can be either local time or UTC time, depending on the feed. For example, in the Le Mans 24h 2024 race (starting at 16:00 CET - 4:00 PM CET), the time sent in the feed is UTC Time:

![](https://help.hhtiming.com/assets/images/race_control_messages_10-30f08fd4ce21afa80db36d3b20c9b344.png)

To display the local time, there are two options:

- Using a manual offset
- Using the offset from the feed (if available)
These options need to be filled out to do that:

![](https://help.hhtiming.com/assets/images/race_control_messages_8-7109d8c818effbce9916bfb2c65a3070.png)

![](https://help.hhtiming.com/assets/images/race_control_messages_11-98fcb011d2218d0f84a5980fd1be8346.png)

## Display decimals​

By default, the time is rounded to the nearest second. For more accurate time display, switching the value of the display decimals is possible in the ribbon bar.

![](https://help.hhtiming.com/assets/images/race_control_messages_12-ee2b4d723d1c8b01f87c206d145705b6.png)

![](https://help.hhtiming.com/assets/images/race_control_messages_13-b40799d4b48690480dc2ecea59a4c136.png)

## Search​

The search bar is used to quickly filter the messages displayed. It is designed to make navigation easier by reducing the number of visible rows to match specific string entered.

![](https://help.hhtiming.com/assets/images/race_control_messages_14-57c197e357aa69680c210b940fd8b40b.png)

The filter is applied in real-time, which means as each character is typed, the list dynamically updates to reflect the relevant rows.

![](https://help.hhtiming.com/assets/images/race_control_messages_15-169a39180ebabf15c9114ec97cf9e113.png)

When the list is filtered, a label appears above the list of messages, indicating that only a subset of messages is being shown.

![](https://help.hhtiming.com/assets/images/race_control_messages_16-76d280d1cdc04fda11b49cde608f7370.png)

To view all messages again, simply clear the text from the search bar.
