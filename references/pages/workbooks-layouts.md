# Workbooks & layouts

This chapter describes how you can use Workbooks and Layouts in HH Timing. Each window of HH Timing is called a workbook. A Layout can consist of one or more workbooks, configured with various displays. Layouts can be saved in the project so that each time the software is run, the same display configuration can be used with no setup required.
