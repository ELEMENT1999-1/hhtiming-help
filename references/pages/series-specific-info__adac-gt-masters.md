# ADAC Gt Masters

## Live Data Connection​

### FTP connection​

To connect live to an ADAC GT Masters event using the FTP access, you need to setup your championship configuration with the following parameters:

#### Protocol​

 |  |
| Protocol | scp.sportresult.com
| Port | 22
| Username | Provided by Swiss Timing
| Password | Provided by Swiss Timing
| FTP Client | winscp

#### Additional Options​

 |  |
| FTP Directory | Different for each event. More info here [https://help.hhtiming.com/timekeeper-specific-info/swiss-timing/#using-filezilla]
| Speed Trap Lines | F, I1, I2
Example FTP directory
Lausitzring 2022:

```
/data/racing/ADAC GT Masters Lausitzring/ADAC GT Masters/
```

### Scrapping interface​

To connect live to an ADAC GT Masters event using the scraping interface, you need to setup your championship configuration with the following parameters:

#### Protocol​

 |  |
| Protocol | SportResult.com HTML Scraping
| Website Season | https://www.adac-motorsport.de/adac-gt-masters
| Alternative Link | https://www.adac-motorsport.de/?redirectId=quer.kmr.motorsport

#### Additional Options​

 |  |
| IFrameName | liveStats
