# Perugia Timing

## Series Using Perugia Timing​

- Italian GT
- Lamborghini Super Trofeo Finals

## Live Data Connection​

Access to the timing feed is via the internet, tethering from a mobile phone connection is generally fine if circuit internet is not available.

You will need to make a new championship configuration [https://help.hhtiming.com/settings-options/championship-configuration] and select Perugia Live Data Connection Protocol.

Use the Host given by Perugia, and the Username, Password you received from them.

![](https://help.hhtiming.com/assets/images/perugia_3-f5cfa6201cf059fb9b3362255c5dce22.png)

EventId is also required to be set in the championship config.

### Find the EventId​

A live timing need to be open in your browser to find the the EventId. It is the last part of the URL:

![](https://help.hhtiming.com/assets/images/perugia_2-c5fcd37da4fa39ac874f12cf936267e1.png)
