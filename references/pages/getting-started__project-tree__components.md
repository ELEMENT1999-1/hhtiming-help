# Components

The Components tree item is shown below in its collapsed state.

[内嵌示意图]

## Car Configuration​

Once any data has been loaded into the project the car numbers in that data will be listed in the Car Configuration as shown below. Double clicking on a car in this list is one way to open a car scoreboard [https://help.hhtiming.com/displays/scoreboards/car-scoreboard] for that car.

[内嵌示意图]

## Category Configuration​

The categories for all the car numbers in the project (as defined in the timing data) are listed in the category configuration.

[内嵌示意图]

Double clicking on a category opens its options where you can define a new category colour that will be used throughout the software.

[内嵌示意图]

## Tyre Manufacturer​

By default Dunlop and Michelin tyres are defined in the software. The tyre manufacturer for each car isn't usually included in the timing feed information, but can be assigned manually in the car options [https://help.hhtiming.com/settings-options/car-options] if needed. These values can be used to colour the cars in the track maps if required.

[内嵌示意图]

## Car Filters​

Car Filters that have been created are listed here.

[内嵌示意图]

## Tracks​

A Default Track is always present in a project when a new project is generated. Any additional track items [https://help.hhtiming.com/settings-options/track-item-ghosts] that are generated are shown in the track list.

[内嵌示意图]

Note that the track in bold is the active track in the software. To Activate, right click and select Activate.

## Championship Configuration​

The championship configuration [https://help.hhtiming.com/settings-options/championship-configuration] is where championship specific information is defined including the timing protocol and connection details. The championship configurations [https://help.hhtiming.com/settings-options/championship-configuration] shown below are shown by default, whichever is bold is currently active. To Activate a championship configuration [https://help.hhtiming.com/settings-options/championship-configuration], right click and select Activate.
