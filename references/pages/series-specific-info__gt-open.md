# GT Open

The GT Open championship uses the Cronococa Enhanced RMon Protocol [https://help.hhtiming.com/timekeeper-specific-info/Cronococa/] for live timing data.

## Live Data Connection​

Create a new championship configuration [https://help.hhtiming.com/settings-options/championship-configuration] and select the Cronococa Enhanced RMon Timing protocol as shown below.

Use the following connection details:

 | Parameter | Value
| Host | 2.136.218.66
| Port | 21546
