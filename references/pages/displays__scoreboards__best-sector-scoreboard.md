# Best sector scoreboard

Summary of the best

- Lap Time
- Theoretical Lap
- Rolling Lap
- Sector Times
- Speed Trap(s)
Unlike the other scoreboards, each car is ranked individually in each column. By highlighting each car you can quickly understand the relative performance of each car.

![](https://help.hhtiming.com/assets/images/bss_1-e66582d71aa9b7438f6331d2e81ee512.png)

If you want to have the average of the x fastest sector time / top speed, or the x% fastest sector time / top speed you can do it by changing this option.

![](https://help.hhtiming.com/assets/images/bss_2-7848e28ff708fd2b0bc3ed4963017d96.png)

The number of laps used for x Best/x Best % is defined in the backstage options:

![](https://help.hhtiming.com/assets/images/bss_3-dca80d1a1335520b2dd01dd8254be2c0.png)
