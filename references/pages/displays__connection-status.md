# Connection Status

The Connection Status display shows the current state of data connectivity and feed health.

![](https://help.hhtiming.com/assets/images/connection_status-a5a2a6cc0cc8f9089363043423c2a6d3.png)

## Status Indicators​

- Last data: shows how many seconds ago the last car-on-track message was received. Displays N/A when no message has been received yet.
- TOD skew: shows the difference between the feed's time-of-day and the computer's UTC clock. A positive value means the feed is ahead; a negative value means the feed is behind. Displays N/A when no time-of-day has been received yet.

## Display Configuration​

The ribbon bar contains the following option:

- Set TOD Datum: zeroes out the current TOD skew value by storing it as a reference offset. This is useful when working with replays or feeds that do not use UTC, where the absolute difference is meaningless but drift over time matters. After setting the datum, the displayed skew represents only the change since the button was pressed.
