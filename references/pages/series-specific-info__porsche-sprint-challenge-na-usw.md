# Porsche Sprint Challenge North America and US West

## Live Feed​

The live timing data is provided by Alkamel [https://help.hhtiming.com/timekeeper-specific-info/alkamel-v2/].

You can purchase a v2 protocol access from the Alkamel North America store.

Internet Requirements
A stable internet connection is required to receive all data throughout the event. Connection interruptions may result in data loss.

v2 Protocol
A championship configuration for v2 protocol can be downloaded here. Username and Password need to be filled in once the config imported [https://help.hhtiming.com/settings-options/championship-configuration/#import-a-championship-configuration] in HH Timing.

![](https://help.hhtiming.com/assets/images/porsche_sprint_3-d3fbc4473125f0231074275ba8419992.png)

## Track Maps​

Track maps for this series can be found under the Porsche Sprint Challenge NA & USW folder:

![](https://help.hhtiming.com/assets/images/porsche_sprint_1-3947464b6b9d6b9bf6d74cb6c6997c8d.png)

## GPS (Track Map, v2 protocol only)​

Alkamel provides GPS positioning [https://help.hhtiming.com/timekeeper-specific-info/alkamel-v2/#gps-track-map-specific-championships] in their v2 feed. You can switch the track map to GPS to have a more precise track map.

## GPS (Speed and driving line, v2 protocol only)​

GPS can also be used to display the speed and the driving line [https://help.hhtiming.com/displays/graphing/gps-speed].

## Post session csv data import​

#### Post-Session CSV Data Import​

CSV files can be downloaded from http://usac.alkamelna.com/ (Analysis CSV)

![](https://help.hhtiming.com/assets/images/porsche_sprint_2-9e1a1ca7b8ab0fcee75454cf3a1c2de2.png)

In HH Timing, WEC/ELMS Alkamel should be chosen as the file format in "Import T&S Data"  to import this file.
