# Fixed stint length

In series where driving time tends to control the stint lengths, using the fixed ftint lengths mode is generally more suitable than using the predicted stint lengths [https://help.hhtiming.com/calculation-definitions/predicted-stint-length] where the limiting factor is considered from a fuel perspective. The settings for the Fixed Stint Lengths can be found in the session settings [https://help.hhtiming.com/settings-options/backstage-options/#session-settings] backstage area.

The fixed stint length values are made use of primarily in the strategy overview [https://help.hhtiming.com/displays/overviews/#strategy-overview] to predict the future stints, the main scoreboard [https://help.hhtiming.com/displays/scoreboards/main-scoreboard] can also show values relevant to fixed stint lengths. In this case the average pace of the previous stints is used to calculate how many laps are likely going to be possible in the future stints of the race for each car. How these future stints fall between cars allows the user to understand the relative strategy implications for each car.

In the case below a Blancpain GT Endurance Series race is shown part way through with a maximum of stint time of 65 minutes. Each of the future stint lengths are based on the total average lap time of each car. Note that Cars 8 and 84 are predicted to be able to do 30 laps while every other car has a maximum of 29 laps.

![](https://help.hhtiming.com/assets/images/fixed_stint_length_1-8b119b771118aed277d5ae8e93f1128d.png)

By default the average of the best 3 in the last 5 green laps will be used to calculate the maximum stint length for each car individually. This can be overridden by enforcing an average lap time on a per class or per car basis in the track item [https://help.hhtiming.com/settings-options/track-item-ghosts].

When a new strategy overview [https://help.hhtiming.com/displays/overviews/#strategy-overview] is created it will use the Predicted Strategy Type defined in the backstage options as shown below:

![](https://help.hhtiming.com/assets/images/fixed_stint_length_2-180ac934df026d0ba0115cd0c6116921.png)

Predicted Stint Lengths is the default value. Please make sure to change it to Fixed Stint Lengths.

The following columns in the main scoreboard [https://help.hhtiming.com/displays/scoreboards/main-scoreboard] use the fixed stint lengths for their future predictions:

- Fixed stint time remaining
- Fixed stint num stops left
- Fixed stint num laps left curr stint
- Fixed stint num laps final stint
- Fixed stint add info
