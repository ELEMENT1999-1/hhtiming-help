## Column Configuration​

The Main Scoreboard is one of the most configurable elements in within the software with many uses other than simply tracking the overall scored position of each car. The columns shown and the order they are presented is customizable using the Column Config button in the ribbon bar control.

![](https://help.hhtiming.com/assets/images/main_2-d99a46c6a8bf0d6c43cff38e2d089d55.png)

Opening the Column Config control brings up the following options. Which values are displayed and column order can be modified here. The order can be modified by using the buttons on the left or by typing a new index in the Column Order column. When applicable the column can be shown in delta to a specified car.

![](https://help.hhtiming.com/assets/images/main_3-62bff15e4807c1a6e09b12eaa500e349.png)

tip
Due to the large number of parameters available in the Scoreboard the Search function is helpful to speed up finding the parameter you are looking for.

## Last Sectors​

When displaying the last sector times columns, use the backstage options [https://help.hhtiming.com/settings-options/backstage-options/#reset-last-sectors-every-lap] to keep the sectors information from the previous lap or clear it after crossing S1.

![](https://help.hhtiming.com/assets/images/main_lastSectors_disabled-6feefe84a540615f79a31c71d50c6f60.png)

#### Clear Sectors enabled​

![](https://help.hhtiming.com/assets/images/main_lastSectors_enabled-9b6078b1420347126e791459481fd3a1.png)

## Scoreboard Export​

The main scoreboard can be automatically exported to an external Excel workbook [https://help.hhtiming.com/excel-exports/scoreboard-live-excel-export] to be used for external calculations.
