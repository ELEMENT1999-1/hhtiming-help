# Remote replays database

The remote replay database allows downloading and running past events replays directly within HH Timing.

Info
This service is currently only available for selected series and events but the list will expand over time.

## How to use it?​

The database can be accessed by clicking on the Load Remote Replay button on the Data ribbon bar:

![](https://help.hhtiming.com/assets/images/remote_replays_database_1-1bcdfc2441fa251ed0d58abb47ab3238.png)

The first time that the tool is launched, the list of available replays will be downloaded from HH Dev database. The user will then be able to select the Series, Year, Event, Session and the type of replay:

![](https://help.hhtiming.com/assets/images/remote_replays_database_2-03ac9d6e65301806f362637e2c84b68e.png)

The replays can then be loaded by clicking on the Load Replay button:

![](https://help.hhtiming.com/assets/images/remote_replays_database_4-082ee9c47dcd7139697acfe277421093.png)

The replays will then be downloaded and start automatically on the computer.

## Championship configuration​

The tool will check to ensure that a correct championship configuration is selected prior to attempting running the replays.

In the case that a wrong championship configuration is activated, an error will be posted to inform the user:

![](https://help.hhtiming.com/assets/images/remote_replays_database_5-6785f679245b1add9c6cd13ccf28b53f.png)

By clicking on the Change button, the user will be prompted with the list of championship configuration suitable to run the replay:

![](https://help.hhtiming.com/assets/images/remote_replays_database_6-2ebfc8b297b8692b4b9726fe2344339a.png)

![](https://help.hhtiming.com/assets/images/remote_replays_database_7-15ef04e95078140c06c8e44643f5b828.png)

## Refresh data​

If changes are being made on the HH Dev database during an event, the list of available replays can be refreshed without restarting HH Timing by clicking on the refresh button:

![](https://help.hhtiming.com/assets/images/remote_replays_database_3-2d7e7446f03cbc08742c472f473c026a.png)
