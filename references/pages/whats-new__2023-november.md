# 2023 November Release

# 2023 November Release

October 25, 2023 · 4 min read

Our 2023 November release includes many improvements to HH Timing. Many of these were requested by you, so thanks for continuously sharing your feedback and ideas!

As usual, if you have any questions or issues with the release please contact us using support@hh-dev.com.

## Help file​

Recently we have released a new help file. The address remains unchanged help.hhtiming.com [https://help.hhtiming.com/]. We have made changes on our side so the help file will receive more regular updates in parallel to the development.

For each version, we will have a post in this section help.hhtiming.com/whats-new [https://help.hhtiming.com/whats-new/] to describe every new feature and major changes to the software.

## HH Timing replay database​

➔ Complete Help section [https://help.hhtiming.com/timing-data-management/remote-replays-database/]

One of the major improvements for this version is the incorporation of a replay database directly within HH Timing. This will allow users to get access and run past replays from the software.

![](https://help.hhtiming.com/assets/images/2023_november_release_2-03e9cda769e5905a7594149bb1820ab3.png)

![](https://help.hhtiming.com/assets/images/2023_november_release_1-94eef6a0de7d30706e0e9527be9591fa.png)

Info
This service is currently only available for selected series and events but the list will expand over time.

## Race calculation on car scoreboard​

➔ Complete Help section [https://help.hhtiming.com/displays/scoreboards/car-scoreboard/#show-future-laps-option]

Future laps based on the race calculation parameters can now be displayed directly in the car scoreboard. This option was designed to help with decision making live during the race and also validate that all parameters have been entered properly in the software.

![](https://help.hhtiming.com/assets/images/2023_november_release_3-95f6254753cbd4a41560b4331be677e5.png)

## Alkamel​

### GPS Speed​

➔ Complete Help section [https://help.hhtiming.com/displays/graphing/gps-speed/]

We have reworked our GPS speed graphs section. Mainly we have adapted the default settings to be best suited for endurance racing and Alkamel protocol. The help file has been reworked as well to better explain each settings and to use the feature.

![](https://help.hhtiming.com/assets/images/2023_november_release_4-6c13f2a4854de9a04af4910f59288d3f.png)

### Retired status​

The status of retired car will be displayed in the Status column of the main scoreboard:

![](https://help.hhtiming.com/assets/images/2023_november_release_5-4ea9719882549c26c5cbb2d3a3d521bb.png)

## Focus on reference car​

➔ Complete Help section [https://help.hhtiming.com/displays/track-maps/full-track/#zoom-on-reference-car]

There is now an option to zoom on a car on the track map:

[内嵌示意图]

The track map will then follow the selected car around the track:

![](https://help.hhtiming.com/assets/images/2023_november_release_14-9e53ed1c89cc285a24371148a499a0f8.png)

GPS

## Track limit​

➔ Complete Help section [https://help.hhtiming.com/displays/track-limits-warning/]

A new display was added called Track Limit warning:

![](https://help.hhtiming.com/assets/images/2023_november_release_6-c66d55bb5e0642bd38b7ddf8c92fb027.png)

This display helps with the monitoring of track limits for specific series.

Track limit counters were also added to the main scoreboard and the driver scoreboard.

![](https://help.hhtiming.com/assets/images/2023_november_release_7-15aaaef09affc9fb17a0c16d9eec0ec2.png)

Also laps invalidated are now recorded and the scoreboard and ranking are also updated accordingly.

## Live crossing order​

➔ Complete Help section [https://help.hhtiming.com/displays/scoreboards/live-crossing-order-scoreboard/#pit-stop-ghosts]

We have added the gap for the ghost cars by showing the expected time to the car in front and to the car behind.

![](https://help.hhtiming.com/assets/images/2023_november_release_8-f3f9b614002cc4210cfa7ba0f27276ec.png)

## Lap analysis scoreboard​

➔ Complete Help section [https://help.hhtiming.com/displays/scoreboards/lap-analysis-scoreboard/#reference-car-display-mode]

In the lap analysis scoreboard we can now display the position of the reference car for the lap time and each sector instead of the time itself. The position is either taken in relation to all cars or just the displayed cars. This allows to compare the ranking for an entire category or a manufacturer:

![](https://help.hhtiming.com/assets/images/2023_november_release_9-baf6a06dde75e3b9418adc393865c7ad.png)

## Main scoreboard past sectors​

➔ Complete Help section [https://help.hhtiming.com/displays/scoreboards/main-scoreboard/#last-sectors]

We have added a new option in the Scoreboard backstage option to reset all sectors following a lap:

![](https://help.hhtiming.com/assets/images/2023_november_release_10-27f94b8f9c2e84fe377b1356520f3adb.png)

The idea behind it is to simplify the scoreboard view especially in a series with a lot of sectors.

![](https://help.hhtiming.com/assets/images/2023_november_release_11-fc108944cacaf40d2482898528de7078.png)

Example with the option set at True:

![](https://help.hhtiming.com/assets/images/2023_november_release_12-4a22983757cbea133d6ca0c6129a1aa7.png)

## Car off track improvement​

There is now the option to play with the speed detection for the car off track when used with GPS mode:

[内嵌示意图]

By default the value is set at 40 kph.

There is also an option on the full track map to not activate the spotter mode. When off, cars detected by the car off track control won't show with an arrow on the full track map:

![](https://help.hhtiming.com/assets/images/2023_november_release_17-d64b4eae91cd39714b5465de9b79b6f1.png)
