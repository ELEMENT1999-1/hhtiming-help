# Scatter

A large number of parameters are available for plotting on a scatter graph with both X and Y axes fully definable. The parameters available for both axes are shown below.

![](https://help.hhtiming.com/assets/images/plotting_1-e93e647b7d1cd5cd979f78cbc1250325.png)

![](https://help.hhtiming.com/assets/images/plotting_2-94e72d06f32bba1918decf1677cc6cd2.png)

Filers can be added to the plot series to only look at ranges of interest. For example of you wanted to remove the In and Out laps from a lap time plot an upper limit can be applied via the Edit Series button in the ribbon control as shown below.

![](https://help.hhtiming.com/assets/images/plotting_3-dba1fe33eefd38a2a55a27b537443b8a.png)

## Reference Car​

Use the Ref Car field in the Scatter Plot options to select a car to use as the reference. When a reference car is set, the chart displays deltas to that car on the Y axis.

[内嵌示意图]

### Relative Delta​

Enable `Relative Delta (%)` to show the Y-axis delta as a percentage relative to the reference car instead of an absolute value. The option is disabled when no reference car is selected.

[内嵌示意图]

## Reference Lines​

Horizontal reference lines can be added to the graph from the Edit Reference Lines button.

[内嵌示意图]

Each reference line includes a name, a Y-axis value, and a color selection.

[内嵌示意图]

The line appears on the charts, with the name shown on the right to differentiate multiple lines.

![](https://help.hhtiming.com/assets/images/reference_3-d435f891fe8a6fc03c84c0d6d5ef4249.png)
