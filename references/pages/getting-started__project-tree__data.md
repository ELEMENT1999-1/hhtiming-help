# Data

Timing data from sessions, Report Profiles and Excel Export Profiles that are part of the project are shown under the Data heading.

[内嵌示意图]

## Sessions​

Session Data that has been used in the project is listed under the Sessions heading. Any session that is bold is currently active, another session can be made active by right clicking and selecting Activate. Static and Replay data is shown in this Session list.

[内嵌示意图]

## Report Profiles​

Report profiles [https://help.hhtiming.com/reporting] that are part of the project are shown under the Report Profiles heading. Double clicking on a Report Profile opens it for editing.

[内嵌示意图]

## Excel Export Profiles​

Excel export [https://help.hhtiming.com/excel-exports/live-excel-export] profiles that are part of the project are shown under the Excel Export Profiles heading. Double clicking on an Export Profile opens it for editing.

[内嵌示意图]
