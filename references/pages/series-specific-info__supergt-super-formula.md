# Super GT & Super Formula

## Live Data Connection​

### RaceNow​

The RaceNow websocket protocol provides detailed live data and replay capability.

It was previously available for both Super GT and Super Formula, but it now works only for Super Formula.

#### Super Formula​

 |  |
| Protocol | RaceNow! Websocket
| Website | ws://superformula.racelive.jp:6001/get
| Number of Sectors | 3 or 4
| Language | japanese or english
The value for the language field will change the writing system for driver and team names. If the value is "Japanese" the Japanese writing system will be used, otherwise it will be the Latin alphabet.

### HTML Scraping​

To connect live to a Super GT event, you need to setup your championship configuration with the following parameters:

#### Super Formula​

 |  |
| Protocol | Super GT / Super Formula HTML Scraping
| Website | http://superformula.racelive.jp/live

## Post Session CSVs Data Import​

In Super GT, organizer can provide you a zip File containing different CSV (one per car and 2 other csv files). To imports datas into HH Timing, you need to:

- Extract the Zip file
- choose the YYYY _Rd.X_TRACK_FINAL.csv as the main import file.
- Make sure all the CarNoX.csv files are in the same directory
