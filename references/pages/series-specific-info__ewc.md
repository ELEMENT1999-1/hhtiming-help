# EWC

## Timing provider​

The timing for EWC is provided by ITS Chrono [https://help.hhtiming.com/timekeeper-specific-info/its-chrono].

If you which to receive the timing feed, you will have to contact ITS Chrono to get an API Key.

## Championship configuration​

![](https://help.hhtiming.com/assets/images/ewc_1-3a58bec33b0fa77244830e89a8721662.png)

 |  |
| Protocol | ITS
| Host | https://api-live.its-live.net/v1/DataFeed
| API Key | YOUR API KEY
| ChampionshipId | ewc
| SeasonId | 2019-20
| EventId | depend of the event (see table below)
| SessionId | auto (for live) or the session number for replaysBe Careful, all fields are case sensitive!

### EventID​
