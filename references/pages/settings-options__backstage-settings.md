# Backstage settings

The backstage settings can be accessed via the File tab in the ribbon bar and selecting the Options button. These settings are a property of the computer rather than being stored in the project. Detailed information for the Backstage Settings are broken down into sub-areas.

![](https://help.hhtiming.com/assets/images/general_1-0587084dba081ff61ec2b3beb9e9362c.png)

The backstage settings are laid out as below into subsections. The explanation for each parameter is broken down into the same subsections below.

![](https://help.hhtiming.com/assets/images/general_2-fc00b1ad7ce1306e69692a95f58e5a59.png)

## Import/Export Backstage settings​

You can export and import your backstage settings. By default it is saved in Documents\HH Timing\Backstage Settings (hhset file).

![](https://help.hhtiming.com/assets/images/general_3-67ddf19467b5144e63c336df6121c197.png)
