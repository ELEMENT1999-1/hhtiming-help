# Workspace

## Ribbon Bar​

The tabs to access all the main software controls are found in the Ribbon Bar.

## Project Tree​

Configuration of displays [https://help.hhtiming.com/getting-started/ribbon-bar], components [https://help.hhtiming.com/getting-started/ribbon-bar] and data [https://help.hhtiming.com/getting-started/project-tree/data] are accessed from the project tree [https://help.hhtiming.com/getting-started/project-tree].

## Displays Area​

Where displays such as scoreboards, track maps, clocks and other displays can be arranged to visualize the data.
