# Tips & tricks

- Use folders to keep the project tree [https://help.hhtiming.com/getting-started/project-tree] organised. Folders can be created by right clicking on the header in the tree, items can then be dragged into the folders with a left click and drag.
- Project tree [https://help.hhtiming.com/getting-started/project-tree] items can be copied by holding the Ctrl key and dragging the item with a left click and drag.
- Multiple project tree [https://help.hhtiming.com/getting-started/project-tree] items can be selected by holding either the Shift or Ctrl keys and left clicking.
- The background colour of new displays can be set to default to white or black in the scoreboard background settings [https://help.hhtiming.com/settings-options/backstage-options/#scoreboard-settings]
- To quickly copy data from a scoreboard to use for calculations externally you can manually copy the scoreboard data by highlighting it and Ctrl+C. This is separate from the CSV Export function available in the scoreboard [https://help.hhtiming.com/displays/scoreboards] ribbon bar.
