# rFactor 2

HH Development has developed a prototype version of HH Timing to be able to connect to rFactor 2. Please contact us if you would like to use HH Timing for your e-races on rFactor 2.

## Connection​

To connect to rFactor 2, your computer will have to also be connected to rFactor 2.

To be able to receive timing information, we are using a .dll coming from here. This will download a zip file. Inside the zip file, you can find the .dll called rFactor2SharedMemoryMapPlugin64.dll.

[内嵌示意图]

Make sure to copy this .dll inside the folder  \rFactor 2\Bin64\Plugins. Depending on which platform you are using for rFactor 2 this location will be different. For user using Steam the location is the following: C:\Program Files (x86)\Steam\steamapps\common\rFactor 2\Bin64\Plugins

The folder should look like that:

![](https://help.hhtiming.com/assets/images/rfactor_2-bb3e77201ef173356a9ab86a57ed4784.png)

Inside rFactor 2, you will have to make sure the .dll is active. This window is accessible from the Options menu under the race center:

![](https://help.hhtiming.com/assets/images/rfactor_3-3db5b5b8d65de0f07b9daef711fec695.png)

Restart
Make sure to fully restart the software the first time you turn the dll/plugin on.

## Championship protocol​

To connect to rFactor 2 timing feed, a new championship configuration would have to be created with the rFactor2 protocol selected. No other information are required.
