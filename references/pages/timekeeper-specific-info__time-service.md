# Time service

## Live Feed​

Time Service provide timing services for a number of championships. For customers using HH Timing, the most common is the Creventic series.

Time Service provide a timing feed that is accessible over the internet which means you will need a stable internet connection during each session. The inputs required to configure the championship configuration [https://help.hhtiming.com/settings-options/championship-configuration] are shown in the image below. The protocol used is "Time Service Team Stream (SSL)". The user should ask for the following information from the timekeepers to ensure the connection is correctly configured:

- Host
- Port
- key (like a unique password given to each team)

[内嵌示意图]

You can also change the value of Allow refresh parameter. If it is set to true, all the messages will be downloaded from Time Service Server. So even if you connect after the beginning of the session, you will get all laps from all cars, including laps completed before you connected. If it is set to false, you will only get data sent after your connection.

Once the championship has been configured correctly you can click the connect button [https://help.hhtiming.com/getting-started/ribbon-bar/data] to connect to the live feed.

## Post Session Static Data Import​

The static data can be imported [https://help.hhtiming.com/timing-data-management/timing-scoring-data-import] into HH Timing to use for analysis. Download the Sector analyse file (open format) from https://getraceresults.com site for the relevant session as shown below.

- Select Event:

![](https://help.hhtiming.com/assets/images/time_service_2-74c0466976a4ccecdbbe972a22cf4a4d.png)

- Click on "Show Exports":

![](https://help.hhtiming.com/assets/images/time_service_3-50b2de9effd05031b0b2efb377468ed1.png)

- Choose the sector analyse file (open format - CSV) for the desired session:

![](https://help.hhtiming.com/assets/images/time_service_4-b4486d9a877be918be0fb1c4fc87f477.png)

- Choose the Result file (open format - CSV) for the desired session: ![](https://help.hhtiming.com/assets/images/time_service_5-8bbdcbb9cc2541a0f51340cb6d0de516.png)
- In HH Timing, choose TimeService as file format in "Import T&S Data" and select the CSV files.
