# Raising Average

The raising average graph can be used to analyse practice/qualifying sessions or a race. The graph is a plot of the average best X laps for different values of X, starting from 1. In the example plot, for the lap number 60 the corresponding y-value shows the average lap time of the best 60 laps for each car. The raising average graph also gives an indication of the consistency of each car/driver. The shallower the slope the more consistent a car/driver is over the corresponding number of laps shown on the x-axis. The raising average plot is useful to see the overall performance of a car/driver in a session, but does not allow for analysis of individual stints or contiguous subsets of laps.
