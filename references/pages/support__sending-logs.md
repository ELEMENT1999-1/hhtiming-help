# Sending log files

To diagnose issues, sometimes we will ask for the error log file. Each time HH Timing is started, a folder for that date is created and a text file "log.txt" will be generated. Relevant events and errors are logged here and help us trace the source of issues.

If you have HH Timing open

File → Support → Open logs folder

![](https://help.hhtiming.com/assets/images/sending_log_3-fc661235dacc827725d9645d85afa093.png)

Using Windows Explorer

To access the error logs, go to the following path:

```
%localappdata%\HH Timing\Logs
```

Here you will see a list of folders, one for each date the software was run as shown below.

[内嵌示意图]

Open the folder for the date relevant to when the issue occurred, and sent the .txt log file as shown below
