# Cronococa Enhanced RMon Timing

When the timing is provided by Cronococa, the Cronococa Enhanced RMon Timing protocol can be used.

This protocol is used for series such as GT Open.

## Live Data Connection​

The connection to the live timing feed is done via the internet, using the host and port values provided by Cronococa.
